# Pomodoro IoT Timer with Flask Web Dashboard

This project implements a MicroPython-based ESP32 Pomodoro timer integrated with a premium glassmorphic Flask web dashboard.

## Basic Operation
1. **Idle State**: Both LEDs are off. The web UI displays "Idle".
2. **Red LED Phase (Timer Active)**: Pressing the button turns on the Red LED and starts the countdown. The web UI displays the countdown in real-time.
3. **Blue LED Phase (Finished)**: After the countdown finishes, the Red LED turns off and the Blue LED turns on. The web UI glows blue.
4. **Cycle Restart**: Pressing the button during the Blue phase restarts the cycle (Red LED phase).
5. **Configuration**: You can dynamically update the Red LED duration in seconds from the web interface.

---

## Getting Started

### 1. Run the Flask Server
Run the local PC server in your project directory:
```bash
python3 server.py
```
The server will start on [http://localhost:5001](http://localhost:5001).

### 2. Expose the Server with Localtunnel
To bridge the Wokwi simulator to your local PC server, expose port `5001` in a new terminal window:
```bash
npx localtunnel --port 5001
```
This will output a URL like `https://funny-emus-run.loca.lt`.

### 3. Update ESP32 Firmware
Copy the URL generated by localtunnel and paste it into the `SERVER_URL` variable on line 10 of `main.py` in Wokwi, **removing the "s" from "https"** (change it to `http://` to prevent SSL errors on the ESP32):

```python
# Example configuration:
SERVER_URL = "http://funny-emus-run.loca.lt"
```
*(Notice we use `http://` instead of `https://`).*

Start the simulation in Wokwi and enjoy the synchronized real-time Pomodoro!
